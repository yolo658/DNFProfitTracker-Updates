## 在线更新清单

程序通过仓库根目录的 `latest.json` 检查最新版本。清单包含版本号、安装包下载地址、SHA-256、文件大小和更新说明。

## 数据安全

安装包不包含任何账号、角色、草稿、收益、金库或司南数据库。用户数据保存在本机：

```text
%LOCALAPPDATA%\地下城收益记录器\data\dnf_profit.db
```

覆盖安装只更新程序文件，不覆盖本机数据库。
