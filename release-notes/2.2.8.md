# 地下城收益记录器 2.2.8

发布日期：2026-08-15

## 角色名称下拉框

- 新增和修改角色时，“名称”改为可输入的下拉框。
- 已经保存过的角色名称会自动出现在下拉列表中。
- 相同名称自动去重，不会在列表中重复显示。
- 可以选择已有名称，也可以直接输入全新的角色名称。
- 账号名称仍然保持普通输入框，不受本次改动影响。

## 等级显示修正

- 角色编辑弹窗不再显示“已提升多少级”。
- 满级角色显示“当前等级｜已满级”。
- 未满级角色显示“当前等级 / 满级等级｜未满级（还差多少级）”。
- 满级判断继续使用“账号与设置”中配置的全局满级等级。

## 数据安全

- 安装包不包含任何本机 `.db`、`.sqlite` 或 `.sqlite3` 数据文件。
- 在线更新只替换程序文件，不覆盖已有账号、角色或收益数据。
