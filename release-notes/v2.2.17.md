# 地下城收益记录器 2.2.17

- 首页增加账号下拉框，今日收益卡片和角色收益排行只显示当前账号。
- 账号数量、各账号角色进度和账号金库总金币继续保留全局展示，不与当前账号收益混算。
- 最终角色金币必须包含售出收入；总产出按照最终角色金币减去开刷前角色金币计算。
- 刷图金币与售出收入分开显示，售出收入仅用于收益来源拆分，不会重复加到角色金币。
- 收益统计将单角色累计信息改为账号角色累计表，当前账号全部角色每人一行。
- 账号角色累计表支持横向、纵向滚动和按累计净利润排序。
- 历史记录编辑、删除及后续角色金币重算继续保留。
- 安装包不包含本机账号、角色、收益、草稿、金库或司南数据库。
